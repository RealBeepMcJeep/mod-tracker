Valheim Mod Tracker — Data Flow & Field Lineage

Manual, deterministic, Python-stdlib pipeline · external sources → raw evidence → normalized flat files → derived rates → single-file report

Source precedence

  • • Thunderstore listing supplies discovery, presentation metadata, pin state, and ranking appearances.
  • • Thunderstore metrics API supplies exact downloads, rating, and latest version.
  • • Nexus GraphQL supplies ranked discovery plus most display and metric fields; v1 detail enriches/fills gaps.

Persistence model

  • • Raw HTML/JSON is retained as source evidence.
  • • data/mods.json is the normalized canonical store with observation history.
  • • No database, service, scheduler, or LLM is required for routine collection/report generation.

Report semantics

  • • The report compares each source record “apples to apples” using common normalized fields.
  • • Lifetime rate is computable immediately; current-version observed rate requires two tracker runs.
  • • Search, source filtering, and sorting happen locally in the generated HTML.

Deliberate safeguards

  • • Credentials and cookies remain runtime-only and outside Git.
  • • Cross-site matches are manual only—never inferred from names.
  • • Mapped records are not statistically combined yet; this avoids false totals from unknown audience overlap.
